# Finance Dashboard / Мій бюджет

Інтерактивний фінансовий дашборд для аналізу банківських транзакцій, управління категоріями й чотирма мегакатегоріями.

## Приватність

У публічному коді немає жодних банківських транзакцій, реквізитів, виписок або приватних JSON-копій. Після завантаження резервної копії дані зберігаються **лише в браузері** через localStorage. Сайт не має сервера та не синхронізує дані між пристроями. Не комітьте приватні виписки, CSV, XLSX чи JSON до GitHub.

**Увага:** сайт GitHub Pages є публічно доступним навіть тоді, коли сам репозиторій приватний. Сайт не має авторизації. Не користуйтесь ним у спільних браузерах.

## Як почати

1. Увімкніть GitHub Pages: **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**. Публікація залежить від плану GitHub: приватний репозиторій підтримується на GitHub Pro/Team/Enterprise, а GitHub Free вимагає public repo.
2. Перейдіть на сайт (після розгортання) `https://angnu.github.io/finance-dashboard/`.
3. Відкрийте вкладку **Дані й копії** та імпортуйте приватну резервну JSON-копію, отриману від ChatGPT, або банківські XLSX/CSV.
4. Працюйте з категоріями, вручну позначайте повернення і перекази, створюйте правила автоматичної класифікації.
5. Регулярно експортуйте **JSON-копію** і зберігайте її приватно.

## Файли

- `index.html` — застосунок без зовнішніх залежностей.
- `.nojekyll` — статичне розміщення без Jekyll.
- `.gitignore` — запобігання випадковому коміту виписок і резервних копій.

Ця версія не є серверною системою з входом за паролем або хмарним збереженням.
